Important for Sunnah.com's recommendation: KFGQPC Uthman Taha Naskh Regular.ttf maps U+FDFA (ﷺ). It can render the ﷺ symbol in Allah's Messenger (ﷺ). Its 30/31 Al-Fātiḥah coverage is a separate test: the one missing character is U+0671 ARABIC LETTER ALEF WASLA (ٱ).

The phrase's English letters should normally come from the site's Latin/UI font. The Arabic font's important job in that phrase is to provide ﷺ. Do not mark an Arabic font as unsuitable just because it does not contain the Latin letters in “Allah's Messenger”.

Why the earlier report called KFGQPC partial: the earlier test asked whether the font mapped every distinct character in this particular Uthmani Al-Fātiḥah specimen. It did not test ﷺ. The updated report tests both independently.

How to interpret the coverage results

  • Unicode cmap coverage: confirms that the font maps the code point to a glyph. It does not prove the glyph is beautifully drawn or that mark placement is correct.
  • Arabic shaping: GSUB joining substitutions and GPOS mark-positioning features are useful indicators, but actual browser shaping still needs visual verification.
  • Fallback: with a font stack, browsers can use the primary font for characters it supports and a later font for missing characters. A line can therefore contain glyphs from more than one font.
  • Unicode ranges: `unicode-range` only declares which code points a font face may supply. It cannot add a missing glyph.

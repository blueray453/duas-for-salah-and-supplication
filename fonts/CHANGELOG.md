# Changelog

## 1.3.0 — 2026-11-23

- Added `--qf-field` to classify text from a known Quran Foundation field.
- Added support for `text_qpc_nastaleeq`, `text_qpc_nastaleeq_hafs`, and deprecated `qpc_uthmani_hafs` alias.
- Added explicit Digital Khatt V1, V2 and IndoPak encoding/rendering metadata choices.
- Expanded the Mushaf ID catalogue with documented page counts.
- Added per-dimension status that distinguishes explicit CLI declarations from Quran Foundation field metadata.
- Expanded test coverage for QF fields and Mushaf pagination metadata.

## 1.2.0

- Added separate orthography, riwayah, script tradition, typography, encoding model and page-layout assessment.
- Added QF field and Mushaf ID catalogue metadata.
- Added font metadata profiles and reference-manifest classification.

Pause marks: the full Madinah set

Tanzil documents six Madinah Mushaf pause-mark classes. The set is represented by six distinct code points; the interchangeable-pause mark appears twice in its real example. A separate Saktah sign (U+06DC) is also tested below because it matters in Hafs reading but is not one of Tanzil's six listed classes.

Verified verse examples with all six pause types

There is no single short Qur'anic passage containing every one of the six pause-mark types. Instead, this project includes the actual example passages listed by Tanzil for each type, so the font can be tested against real text rather than an invented verse.

How to interpret this report

  • Unicode cmap mapping confirms the font has a character-to-glyph mapping for a code point. It does not guarantee correct visual shape or mark placement.
  • Arabic shaping depends on shaping tables such as GSUB/GPOS and browser shaping support. Correct attachment and positioning of stacked marks must be checked visually.
  • Fallback can make an unsupported character appear on screen using another font. Coverage results always refer to the selected font's own cmap.
  • unicode-range only tells the browser which characters a font face may supply. It cannot add a glyph absent from the font.
  • Tradition differences matter: the six Madinah marks, Saktah signs, Indo-Pak letter-based pause notation and the additional Unicode annotation repertoire are related but not identical sets.

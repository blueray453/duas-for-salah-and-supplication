Your own CSS is dropped by default, so the look stays consistent. Add --keep-styles to keep your <style> tags. Expect to adjust the result, since your styles may fight the print layout.
Relative images work, because the script uses your HTML file’s folder as the base path.
Each h1 starts a new page. To change that, edit break-before: page in the .content h1 rule.
Fonts must be installed on the machine running the script. To embed them from files instead, add @font-face rules pointing at your .ttf files in the CSS template.
Arabic digits and Bangla digits in your text render as written. The page numbers are Western digits, and you can change that in the @bottom-center rule.
